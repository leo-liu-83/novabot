# 功能说明

本文按用户可见能力介绍 NovaBot。配置字段见 [配置参考](configuration.md)，命令见 [命令参考](commands.md)。

## 1. 对话与会话

- TUI 与 Web 共用会话和消息历史
- 流式输出；支持停止生成、重问、逐轮工具调用展示
- 会话标题可重命名；删除会话会清理对应 checkpoint、附件和产物
- 上下文接近窗口上限时自动压缩；也可手动 `/compact`
- 压缩条目会持久化，重开会话后可回看压缩前后信息
- 消息历史支持分页加载，长会话不会一次全部渲染
- 会话可以归属项目，工作根变成项目目录；项目本身的规则见 [§13 项目](#13-项目project)

## 2. 模型接入

- 支持多个 provider 同时配置：厂商官方接口、聚合平台、内网模型
- 使用 OpenAI `/chat/completions` 兼容协议
- 支持 provider / 模型级自定义请求头，token 可放在任意 header
- 支持 `${session_id}` 动态请求头，以及 `x-opencode-session` 自动填充
- 支持动态模型发现：不写 `models` 时从 `/models` 拉取；写了 `models` 则作为静态白名单
- 支持思考开关和不同端点的思考参数写法
- 每个会话可单独选择模型；新会话页选择的模型会用于首次请求

完整说明见 [模型配置](model-config.md)。

## 3. 多用户与身份

- 匿名、普通用户、管理员三种身份
- 注册、登录、登出、改密、注销
- TUI 登录凭证持久化；改密会使其他设备登录失效
- 首次登录时可把当前匿名会话过户给新用户
- 管理员可为账号分配执行天花板和搜索配额
- 管理员可开放/关闭某个账号的 MCP 能力

## 4. 技能系统

技能分三层：

| 层 | 来源 | 可见性 |
|---|---|---|
| 系统层 | 随发行版内置 | 所有账号只读 |
| 共享层 | 公共工作区 | 所有账号可见 |
| 私有层 | 用户工作区 | 本人或管理员可见 |

内置技能随发行版分发，目前有两个：`skill-creator`（创建与改进技能）与 `project-notes`
（把项目知识沉淀到 `AGENTS.md` 与项目笔记，并区分项目细节与全局记忆）。`project-notes`
按项目类型附带参考文档（当前为 Python），模型按需读取；新增类型只需在 `references/` 下加一份
文档并登记。内置技能只读；想改行为可以在自己的私有技能目录建同名技能覆盖（同名时层级靠后的生效）。

核心规则：

- 脚本技能默认不加载，需要扫描并放行
- 纯提示词技能默认加载，但仍可被拒绝
- 放行绑定内容哈希；内容变化后需要重新扫描和放行
- 未放行技能的正文不会通过文件工具直接点名读取
- 管理员可放行危险技能；普通用户只能放行安全技能
- 扫描是咨询性的，不等于安全审计

## 5. 附件与多模态

- TUI 支持路径粘贴、文件管理器拖入路径
- Web 支持选择文件、拖入、剪贴板文件
- 图片可作为视觉输入发给支持视觉的模型
- PDF / Office / EPUB / RTF 可本地转换为 Markdown 后读取
- 文本直接内联；音视频只提供路径
- 默认普通用户：每条消息最多 5 个附件，单文件 10MB
- 管理员 / 单用户机主默认不受附件数量和大小限制
- 未发送草稿附件超过保留天数后会在启动时清理；已发送附件不删

详细限制见 [配置参考](configuration.md)。

## 6. 网络搜索与抓取

### 搜索

- 三档优先级：用户自备 provider → 全局 provider → 内置免费兜底
- 用户自备接口不消耗 NovaBot 配额
- 全局和免费档受每用户每日配额限制
- 任一档失败或返回空结果会自动降级
- 端点故障会在聊天页给出可见提示，同一端点每会话只提示一次

### 抓取

- `webfetch` 默认逐 URL 确认
- `ask` 模式下 allowlist 域名免确认；其他域名仍可抓取但需要确认
- `allow` 模式免确认；`deny` 模式不注册工具
- 拒绝 localhost、内网、链路本地和云元数据地址
- 每一跳重定向重新校验；内容有大小和字符上限
- 抓取内容按不可信外部内容包装

## 7. MCP

- 支持 Streamable HTTP MCP server
- 系统层 server 随发行版配置，默认启动
- 用户层 server 默认关闭，需管理员开放账号的 MCP 能力
- 工具采用延迟发现：先 `mcp_list`，再 `mcp_call`
- server 级审批模式 + 逐工具覆盖：`allow` / `ask` / `deny`
- 每个用户可连接数量有上限
- 工具说明有上下文预算，避免把大量 schema 常驻提示词

## 8. 人格、提示词与长期记忆

- 核心提示词 + 个性化文件 + 用户自定义指令
- 登录用户可维护 `SOUL.md`（Agent 人格）和 `USER.md`（用户属性）
- `prompt.md` 可覆盖默认行为
- 长期记忆分 `core.md` 索引和多个分类文件
- `/remember` 写入记忆，`/memory` 查看
- 匿名身份没有个性化和长期记忆

## 9. 执行档位

| 档位 | 能力 |
|---|---|
| T0 | 不执行任何命令 |
| T1 | 只运行已放行技能 `scripts/` 下的 `.py` |
| T2 | 工作区内单条只读命令 |
| T3 | 任意 shell，每条命令确认 |
| T4 | 任意 shell，免确认 |

无论档位如何，硬黑名单命令都会被拒绝。详细边界见 [安全与权限](security.md)。

## 10. 界面与国际化

- TUI：Textual 界面；`Ctrl+Q` 退出，`Ctrl+T` 切换主题
- Web：浏览器控制台，支持桌面和窄屏布局
- 中英双语：Web 顶栏切换，TUI `/lang`
- 主题：亮色 / 暗色 / 跟随系统（Web）
- Windows TUI 带中文输入法兼容补丁

## 11. 数据与持久化

- 会话、消息、账号、技能审查、配额在本地 SQLite
- checkpoint 支持重启后继续会话
- 会话附件、压缩历史、大工具结果按会话目录隔离
- 数据库不可用时会降级为内存模式，并在界面明确提示“不持久化”

## 12. 管理报表

管理员可以在「报表」页查看统计聚合：

- 用户活跃：期间活跃、DAU/WAU/MAU、新增用户、会话、轮次
- 模型使用：各模型调用次数、使用人数、token 占比、Top 模型
- Token 消耗：输入/输出趋势、每轮平均、Top 用户与模型
- 时间范围支持近 7 / 30 / 90 天，粒度支持按天 / 按周
- 报表只返回聚合数据，不展示消息正文
- 历史模型明细由旧轮次回填时，调用次数是近似值

## 13. 项目（Project）

项目把会话和真实目录绑在一起。它不是复制或搬迁目录，而是**登记一个已有目录**，之后的文件读写与项目知识都以它为中心。

核心概念：

| 概念 | 说明 |
|---|---|
| 项目 | 名称 + 目录 + 描述 + 推荐技能；同一账号下活动项目的名称与目录唯一，归档后可复用 |
| 归属 | 会话可以归属项目，也可以不归属；不归属的会话行为不变 |
| 工作根 | 项目会话的工作目录是项目目录，读写边界限定在项目内 |
| 项目知识 | 项目根 `AGENTS.md` 常驻注入（超长截断）；`.novabot/notes/*.md` 只给文件名索引，正文由 agent 按需读取 |
| 推荐技能 | 只是优先推荐，不改变技能的可见性与审核门 |

权限与边界：

- 项目功能是独立授权：单用户机主默认可用；多用户下由管理员用 `/project-limit` 为账号开通，管理员自身自动可用
- 项目目录内的读写直接放行；项目外路径与敏感文件需要确认
- 项目会话的 shell 默认封顶 T3；T4 只能由用户显式 `/exec` 提到，语义也从"任意命令免确认"收窄为"项目内免确认"，点名项目外的命令仍要确认
- 确认卡里的"总是允许"按具体路径记忆，只在当前会话内生效；会话转入或切换项目时会清掉这些批准记录，避免带进新项目
- 归档项目只停止使用，不删除目录，也不移动已有文件

入口：

- Web：项目页（`#/projects`）创建、改名、归档项目，编辑或让模型生成项目 `AGENTS.md`，查看项目内会话
- TUI：`/project` 在当前目录创建或重命名项目（新建时若当前会话还没有归属，会顺手转进去）；`/session` 里能看到会话所属项目

明确的非目标：不自动创建或搬迁项目目录，不做项目间共享，不做项目级长期记忆，不提供进程级沙箱。
